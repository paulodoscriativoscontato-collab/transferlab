# Transferlab

Baixe vídeos e áudios em máxima qualidade (até 4K/8K, MP3, WAV, FLAC e outros) numa interface simples para Windows.

## Download

Pegue o instalador mais recente em **[Releases](../../releases/latest)** (`Transferlab-Setup-x.y.z.exe`).

- Requer o [ffmpeg](https://ffmpeg.org) instalado: `winget install Gyan.FFmpeg`
- O app avisa sozinho quando houver uma versão nova.
- Na primeira instalação o Windows pode mostrar um aviso do SmartScreen: clique em **Mais informações** e depois em **Executar assim mesmo**.

## Uso responsável

Baixe apenas conteúdo que você tem direito de baixar. Respeite os termos de uso das plataformas e os direitos autorais.
